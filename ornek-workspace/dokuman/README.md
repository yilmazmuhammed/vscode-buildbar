# dokuman

Bu klasor kasten bos birakildi: icinde ne `.vscode/tasks.json` ne de
`CMakePresets.json` var.

BuildBar agacinda "gorev yok" olarak gorunur. Bu klasordeki bir dosyayi
acin: ust sagdaki iki ikon kaybolur ve alt soldaki etiket
`dokuman: gorev yok` olur -- onceki projenin butonlari ekranda kalmaz.
Filtrelemenin gercekten calistigini dogrulamak icin bunu kullanin.
